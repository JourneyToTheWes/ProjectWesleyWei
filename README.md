## Getting Started

### Work Locally
After cloning the repository, we can execute the following steps to start working locally.

> Prereqs: Set up MongoDB (local or Atlas), once their is a collection setup with all of the proper DB 
schemas, then add your connection string as `MONGO_URI` in `backend/.env`.

1. Change directory into `backend`
    1. Run `npm install`
    2. Run `npm run dev`
2. Change directory into `frontend`
    1. Run `npm install`
    2. Run `npm run dev`

Congratulations! We should now have a running WestWay application locally.
